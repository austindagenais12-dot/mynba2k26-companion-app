# Star Wars: Shattered Fates

A self-contained, offline-friendly procedural Star Wars text RPG prototype with Expo, Codemagic, and GitHub Actions Android build support.

## Included

- Randomized or custom lore timeline and starting scenario
- Canon-aware era anchors with optional Legends-flavored and what-if modes
- Character customization: name, pronouns, species, homeworld, archetype, Force path
- Procedural travel, exploration, jobs, social scenes, training, Holonet rumors, rest, and time advancement
- Hidden skill checks, progression, perks, inventory, credits, health, reputation, notoriety, and world tension
- Persistent relationships with trust, respect, friendship, loyalty, rivalry, resentment, influence, and closeness
- Generated contacts, story threads, faction standings, world news, visited locations, and chronological history
- Device autosaves plus portable JSON export/import
- Android-ready Expo wrapper with a Codemagic release APK workflow and GitHub Actions fallback

Open `starfall-shattered-fates.html` directly to play the browser version. The Android build uses that same file as a bundled offline asset.

See `ANDROID_BUILD.md` for the Codemagic, GitHub Actions, and EAS APK build commands.
