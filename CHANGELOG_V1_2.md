# NBA 2K26 Career Companion — Version 1.2.1

## 2K Screen Scanner

- Added small camera buttons for game stats, player overview, attributes, badges, and league transaction logs.
- Added camera capture and existing-screenshot selection.
- Added on-device Android text recognition; images and recognized text do not need a cloud OCR service.
- Added a required review sheet with current/scanned comparisons and per-row selection.
- Added NBA 2K-style box-score parsing, including labeled stats, shooting pairs, table columns, opponent/result, and playoff importance.
- Added recognition for all companion attribute names and supported badge tiers.
- Added player overview recognition for team, position, OVR, potential, age, jersey, height, and weight.
- Added batch parsing for trades, free-agent signings, waivers, releases, and waiver claims.
- Added duplicate protection for transaction-log imports.
- Added a recent confirmed-scan history under More → Settings.
- Kept manual entry available everywhere as the fallback for unreadable or unusual 2K screens.
- Preserved the existing save key and migrated older careers to schema Version 3.
- Updated the app version to `1.2.0` and Android `versionCode` to `3`.

## Android launcher icon

- Added an original basketball, career-progress, and screen-scan launcher mark matched to the app's charcoal/coral palette.
- Added a combined legacy Android icon and a safe-zone adaptive foreground layer.
- Added an Android 13+ monochrome layer for themed launcher icons.
- Kept the artwork free of NBA, 2K, team, letter, and number marks.
- Advanced the app version to `1.2.1` and Android `versionCode` to `4` so the icon build can install as the next app update.
