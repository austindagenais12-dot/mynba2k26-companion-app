# NBA 2K26 Career Companion — Version 1.1

## Player Setup Update

- Added a first-launch **Create Your Prospect** screen.
- Added editable fields for:
  - Player name
  - Position
  - Age
  - Height
  - Weight
  - Hometown
  - Nationality
  - Dominant hand
  - High-school year
  - Starting high school / academy / club
  - Jersey number
- Added validation for age, weight, jersey number, and required identity fields.
- Added **More → Player → Edit profile** so identity details can be changed after a career starts.
- Existing Version 1 local saves migrate to Version 2 schema and show the setup screen once without deleting career progress.
- Kept the existing save key so installing the update over Version 1 preserves the local career save.
- Updated the prospect randomizer so it preserves the user-created identity/body/position/school/jersey information and only randomizes basketball ability, upside, following, marketability, and personality.
- Starter social/news copy updates to the chosen identity on initial setup.
- App version updated to `1.1.0`; Android `versionCode` updated to `2`.
