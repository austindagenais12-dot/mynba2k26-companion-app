NBA 2K26 Career Companion Android V1.1 — GitHub Update

1. Download and extract NBA2K26_Career_Companion_Android_V1_1.zip into Internal storage > Download.

2. In Termux:

cd ~/mynba2k26-companion-app

cp -r ~/storage/downloads/NBA2K26_Career_Companion_Android_V1_1/. ~/mynba2k26-companion-app/

git add .

git commit -m "Add player setup and profile editor V1.1"

git push

3. In Codemagic, start a new Android Release build from branch main.

Important: Do not delete the existing app before installing the update if you want Android to preserve the current local career save. The APK must use the same application package/signing identity as the existing installation for Android to install it as an update.
