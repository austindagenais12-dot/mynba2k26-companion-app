# NBA 2K26 Career Companion — Version 1.3.0

## Draft class

- Added multi-image OCR import for NBA 2K26 draft-board pages.
- Added required per-prospect review before importing.
- Added complete manual add, edit and remove controls for draft prospects.
- Added rank, school, height, weight, draft year and source metadata.

## Schedule and calendar

- Added a dedicated bottom Calendar tab.
- Included all 1,230 games in the completed 2025–26 regular-season schedule, with 82 games per team.
- Added team/month browsing and home/away display.
- Added selection of up to 20 schedule screenshots in one import.
- Added 2K Confirmed schedule overrides and a safe Modern Era baseline restore.

## MyNBA Eras and rosters

- Added all six NBA 2K26 MyNBA starts: Magic vs. Bird, Jordan, Kobe, LeBron, Steph and Modern.
- Added 2,536 offline player-season roster records across historically accurate 23-, 27-, 29- and 30-team leagues.
- Era selection now controls available draft-result teams, game opponents, player/team scanning and transaction scanning.
- Added an era roster browser under More → League.
- Added a season-aware historical league tracker from 1983–84 through 2025–26.
- Active team lists now follow real expansion, relocation and rebrand seasons, including Charlotte/Miami, Minnesota/Orlando, Toronto/Vancouver, Memphis, Brooklyn and Oklahoma City transitions.
- Added historical rule snapshots for Finals/Playoffs formats, defense, backcourt timing, shot-clock resets, three-point geometry, the Draft Lottery, Coach's Challenge, Play-In and NBA Cup.
- Advancing a completed career season also advances the historical league tracker and surfaces that season's changes.

## MyPLAYER animations

- Added optional recommendations for jump-shot bases, dribble styles, layup styles, signature dunks, pass styles and motion styles.
- Suggestions use saved height, position and relevant attributes.
- Added requirement notes and an explicit reminder that suggestions are optional and should be confirmed inside NBA 2K26.

## Platform and migration

- Advanced save schema to version 4 while preserving existing saves.
- Advanced app version to 1.3.0 and Android versionCode to 5.
- Kept the Android package and signing workflow unchanged for in-place updates.
- Made GitHub Actions APK/artifact names derive automatically from app.json.
